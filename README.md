# Kitchen Hands Website

موقع ثابت بسيط وجاهز للنشر عبر GitHub Pages.

## الملفات
- `index.html`
- `styles.css`
- `assets/kitchen-hands-hero.png`

## النشر على GitHub Pages
1. ارفع جميع الملفات إلى جذر مستودع `kitchenhands-site`.
2. افتح: Settings → Pages.
3. تحت **Build and deployment** اختر:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
4. اضغط **Save**.
5. انتظر دقيقة أو دقيقتين وسيظهر رابط الموقع.
